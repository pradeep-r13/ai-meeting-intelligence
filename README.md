# AI Meeting Intelligence & Decision Tracker

Enterprise AI platform for meeting transcription, decision extraction, task management and searchable meeting memory.

## Tech Stack

Backend:
- FastAPI
- PostgreSQL
- Redis

AI:
- LangChain
- LangGraph
- RAG
- Qdrant

Frontend:
- Streamlit

Infrastructure:
- Docker



## Start Infrastructure

Run:

docker compose up -d


Check containers:

docker ps


Stop:

docker compose down
